
# PAAV – Sistema de Hamburgueria e Açaíteria

### Acessar o Site 

https://paav-hamburgueria-acaiteria.lovable.app

## Sobre o projeto

O PAAV é um sistema web desenvolvido como projeto final da disciplina de Programação para Internet.

O projeto consiste em uma plataforma para uma hamburgueria e açaíteria, permitindo que os clientes visualizem o cardápio, conheçam os produtos disponíveis, adicionem itens ao carrinho e realizem pedidos de maneira simples e organizada.

A proposta é facilitar o atendimento e melhorar a organização dos pedidos, oferecendo mais praticidade tanto para os clientes quanto para o estabelecimento.

## Trilha escolhida

**Desenvolvimento Web Full Stack**

A trilha foi escolhida porque o projeto envolve o desenvolvimento de uma aplicação web completa, trabalhando com frontend, backend, API e banco de dados.

## Problema real que o sistema resolve

Muitas hamburguerias e açaíterias de pequeno porte realizam seus pedidos principalmente por mensagens de WhatsApp ou atendimento presencial. Isso pode dificultar a organização dos pedidos, a consulta aos preços e a visualização dos produtos disponíveis.

O PAAV busca solucionar esse problema oferecendo uma plataforma onde os clientes podem consultar o cardápio, criar uma conta, adicionar produtos ao carrinho e realizar pedidos.

Dessa forma, o sistema pretende facilitar o atendimento, melhorar a organização dos pedidos e proporcionar mais praticidade.

## Funcionalidades previstas

- Cadastro de clientes.
- Login e acesso à conta.
- Recuperação de senha.
- Visualização do cardápio.
- Produtos separados por categorias.
- Carrinho de compras.
- Adição e remoção de produtos.
- Cálculo automático do valor dos pedidos.
- Finalização de pedidos.
- Escolha da forma de pagamento.

## Modelagem do banco de dados

O banco de dados do PAAV será organizado em oito tabelas:

1. USUARIOS
2. CATEGORIAS
3. PRODUTOS
4. CARRINHOS
5. ITENS_CARRINHO
6. PEDIDOS
7. ITENS_PEDIDO
8. PAGAMENTOS

A modelagem utiliza chaves primárias (PK), chaves estrangeiras (FK) e relacionamentos para organizar as informações dos clientes, produtos, carrinhos e pedidos.

## Como usamos Inteligência Artificial

### Ferramenta utilizada

**Lovable**

Utilizamos o Lovable como ferramenta de apoio para criar o protótipo visual do PAAV.

### Prompt utilizado

Solicitamos à ferramenta a criação de um site responsivo para uma hamburgueria e açaíteria, com identidade visual nas cores roxa e vermelha.

O prompt orientou a criação de páginas como:

- Página inicial.
- Tela de login.
- Tela de cadastro.
- Recuperação de senha.
- Cardápio.
- Carrinho de compras.
- Finalização de pedidos.
- Sobre nós e contato.

Também solicitamos um site simples, organizado e funcional, adequado a um projeto acadêmico.

### O que ficou da IA?

Aproveitamos a estrutura inicial das páginas, a organização visual, a combinação de cores, a disposição dos produtos e as funcionalidades simuladas do carrinho e dos formulários.

### O que mudou?

Durante o desenvolvimento, foram feitas alterações nas orientações iniciais:

- Alteração do nome do projeto para PAAV.
- Definição da tela de login como primeira página do sistema.
- Ajustes na navegação entre as páginas.
- Adaptação das funcionalidades às necessidades do projeto.

A inteligência artificial foi utilizada como ferramenta de apoio. As decisões sobre a estrutura do sistema, suas funcionalidades e a modelagem do banco de dados foram definidas pela equipe.

## Objetivo final

Desenvolver um sistema web funcional para uma hamburgueria e açaíteria, colocando em prática os conhecimentos adquiridos na disciplina de Programação para Internet, envolvendo desenvolvimento de interfaces, criação de API e modelagem de banco de dados.
